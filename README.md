# Rim Embark

A Dwarf Fortress inspired filter system for the "Select starting site" screen, the gravship destination screen (Odyssey) and the
caravan route planner. Pick what you want (and what you don't),
and every tile that matches lights up on the planet. My least favorite part of starting a new game, and I have to do it a lot because I'm terrible at the game... :)

- Include or exclude biomes, terrain, stone, rivers, roads, map features, landmarks and more
- Set ranges for temperature, growing period, rainfall, elevation, movement difficulty, animal density, pollution and
  distance to the nearest faction base
- Choose per category if a site needs all or any of what you included
- Click the biome, terrain, stone, river, road, landmark or a map feature in the terrain tab to include (left
  click) or exclude (right click) it
- On the gravship screen, only sites within range of your gravship are shown (can be turned off)
- "Random match" jumps to a random matching site you haven't looked at yet
- Filters are remembered between games, separately for each screen
- Hide it with the icon in the world map's bottom right toggles

## Compatibility

Requires Harmony. Works on 1.6 and 1.7, with or without DLCs. It only does something on these screens and doesn't touch your save, so it's safe to add or remove at any time.

Works with Map Preview, it moves its preview window to the left of the RimEmbark menu, so they don't overlap.

Works with any mods adding biomes and map features.

Works with Faction Territories: a filter, on by default, hides sites inside another faction's territory.
